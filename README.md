# Sistema-Hospitalar-Inteligente
Sistema-Hospitalar-Inteligente
Este projeto consiste num software de gestão hospitalar concebido para automatizar a triagem de pacientes em tempo real. O sistema analisa os sinais vitais na receção através de um modelo de **Machine Learning**, gerando instantaneamente uma **Fila de Atendimento Otimizada** por gravidade clínica.
